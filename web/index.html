How this control center works

The browser talks to a Python server bound to 127.0.0.1. The server invokes only documented factory commands and shows their actual output. It cannot verify factual accuracy, captions, pronunciation, or visual quality.

If a button reports an unknown command, your local factory CLI differs from the supplied instructions. The error is shown rather than faking success.
